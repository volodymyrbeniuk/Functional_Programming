## Структура

- `main.py` — точка входу; викликає наявну `app.main()` без зміни її інтерфейсу;
- `app.py` — підготовка прикладів і виведення;
- `core.py` — функції розрахунку;
- `tests/` — тести обчислювального ядра;
- `report/` — звіт лабораторної роботи.

## Встановлення залежностей

```bash
python -m pip install -r requirements.txt
```

## Запуск

З цієї папки виконайте:

```bash
python main.py
python -m pytest tests -q
```
