## Мета

Закріпити функціональні прийоми Python на задачі «перетворення набору записів конвеєром функцій вищого порядку».

## Теоретичні відомості

Функціональний підхід відокремлює перетворення даних від побічних ефектів. Чисті функції дають однаковий результат для однакових аргументів, не змінюють вхідні значення та спрощують перевірку. Композиція малих функцій формує конвеєр, а незмінні значення зменшують приховані залежності. Для роботи з помилками, лінивими даними та асинхронністю використовуються відповідні явні типи та межі.

## Хід роботи

У `lab.py` реалізовано приклад теми лабораторної: функції map/filter/reduce та композицію перетворень студентських записів. Приклад запуску для кожної роботи наведено нижче:

```bash
python lab2/lab.py
```

## Висновок

Реалізація демонструє основну ідею теми: обчислення подано невеликими функціями з визначеними входами й виходами. Для поглибленої здачі доцільно перевірити граничні випадки через pytest та виконати статичні перевірки Black, Ruff і mypy, як зазначено в README.
