## Мета

## Теоретичні відомості

Рекурсивна функція розв’язує задачу через меншу підзадачу того самого типу. Коректна реалізація має базовий випадок, який зупиняє обчислення, і крок, що наближає аргумент до цього випадку. Для списку це перехід від послідовності до її хвоста, для дерева — перехід до лівого та правого піддерев. Результат для більших структур складається з результатів для менших частин.

Мемоізація зберігає результат функції для вже обчислених аргументів. Вона особливо корисна для рекурсії з перекривними підзадачами, як у числах Фібоначчі. Наївна рекурсія Фібоначчі має експоненційну кількість викликів, тоді як кешування `fibonacci(n)` обмежує кількість різних підзадач лінійною функцією від `n`.

Хвостовою називають рекурсію, у якій рекурсивний виклик є останньою дією. Деякі мови оптимізують такі виклики, повторно використовуючи стековий кадр. Python такої оптимізації (TCO) не виконує, тому глибина викликів обмежена лімітом інтерпретатора. Для дуже глибокої обробки даних слід застосовувати цикл або явний стек.

## Хід роботи

### Рекурсія над послідовностями

У програмі реалізовано `recursive_sum`, `recursive_map`, `recursive_filter` і `recursive_factorial`. Кожна функція має окремий базовий випадок для порожньої послідовності або мінімального значення, після чого рекурсивно обробляє меншу задачу. Функції створюють результат і не змінюють передані послідовності.

### Сортування quicksort

Функція `quicksort` обирає опорний елемент і формує три частини: менші за опорний, рівні йому та більші за нього. Вона рекурсивно сортує крайні частини й об’єднує їх із середньою. Такий поділ правильно обробляє повторювані значення та повертає новий список, залишаючи вхідні дані незмінними.

Середня часова складність quicksort становить `O(n log n)`, найгірша — `O(n²)` за невдалого поділу. Додаткова пам’ять потрібна для проміжних списків і рекурсивних викликів. `randomized_select` є додатковою реалізацією пошуку елемента заданого рангу: вона перебудовує лише локальну копію послідовності й не сортує весь набір.

### Рекурсивна обробка дерева

`BinaryTreeNode` — незмінний вузол бінарного дерева. Генератори `inorder_gen`, `preorder_gen` і `postorder_gen` проходять дерево у трьох стандартних порядках; однойменні функції без суфікса повертають результат як список. `tree_size` рахує вузли, а `tree_height` визначає кількість вузлів на найдовшому шляху від кореня до листка.

Для всіх обходів часова складність становить `O(n)`, оскільки кожний вузол відвідується один раз. Глибина стека дорівнює висоті дерева `h`: для збалансованого дерева це близько `O(log n)`, для виродженого — `O(n)`. Генератори видають елементи поступово й не створюють підсписки для кожного вузла.

### Мемоізований Фібоначчі

Функція `fibonacci` має базові значення `F(0) = 0` і `F(1) = 1`; для інших аргументів використовує рекурентну формулу `F(n) = F(n - 1) + F(n - 2)`. Декоратор `lru_cache(maxsize=None)` зберігає результати. Для порівняння `fibonacci_naive` рахує ті самі числа без кешу, тому призначена лише для малих значень.

## Висновок

У роботі реалізовано рекурсивні функції для списків, quicksort, пошук порядкової статистики, обходи незмінного бінарного дерева та мемоізований Фібоначчі. Тести охоплюють базові випадки, повтори, граничні аргументи та збереження вхідних даних. Мемоізація прибирає повторні обчислення підзадач, але не усуває обмеження глибини рекурсії: Python не оптимізує хвостові виклики, тому для глибоких структур доцільні ітеративні алгоритми.
