# Лабораторна робота №4

**Варіант 2**

Тема: рекурсія, обходи бінарного дерева та мемоізація.

## Завдання

Реалізувати чисті рекурсивні операції над послідовностями, алгоритм quicksort, обходи дерева та мемоізований алгоритм Фібоначчі. Пояснити складність рекурсивних обчислень і відсутність оптимізації хвостових викликів у Python.

## Реалізація

- `recursive_sum`, `recursive_map`, `recursive_filter`, `recursive_factorial` демонструють базовий і рекурсивний випадки.
- `quicksort` повертає відсортовану копію, не змінюючи вхідну послідовність.
- `BinaryTreeNode` — незмінна структура (`frozen=True`); `inorder`, `preorder`, `postorder`, `tree_size` і `tree_height` обходять її рекурсивно.
- `fibonacci` використовує `functools.lru_cache`; `fibonacci_naive` залишено для порівняння на невеликих значеннях.
- `randomized_select` додатково демонструє пошук k-тої порядкової статистики без сортування всієї послідовності.

## Зауваження про рекурсію в Python

Кожний рекурсивний виклик займає кадр стека. Python не виконує оптимізацію хвостових викликів (TCO), тому глибока рекурсія може завершитися `RecursionError`, навіть якщо рекурсивний виклик є останньою операцією функції. Для великих вхідних даних потрібно обирати ітерацію або явний стек. Докладний звіт з прикладами й аналізом складності: [report.md](report.md).
